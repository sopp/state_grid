# 国家电网 Home Assistant 集成

[![GitHub release](https://img.shields.io/github/v/release/tiejiang29/state_grid.svg)](https://github.com/tiejiang29/state_grid/releases)

读取 95598（国家电网）账户的余额、日/月/年用电与分时数据。**取数走两条路**：优先用国网 App 的接口（无验证码、无需大模型），App 不成时回落到网页接口（需要 LLM 解验证码），还可以由 sidecar 用真实浏览器抓一份响应推进来兜底。

数据获取与解析逻辑沿用 [bilezhou/state_grid](https://github.com/bilezhou/state_grid)（MIT），未改语义。

## 两条供数路径

| | App 通道（默认，优先） | 网页通道 + sidecar 兜底 |
|---|---|---|
| 入口 | 集成内置，`app_api.py` | 集成内置；sidecar 见 `sidecar/README.md` |
| 需要验证码/LLM | ❌ 不需要 | ✅ 需要（点选/滑块） |
| 需要浏览器 | ❌ | sidecar 需要（Playwright + Chrome） |
| 供数频率 | 每小时灌一次缓存 | sidecar 每日一次推送；网页按刷新间隔自取 |
| 登录额度 | 会话令牌 15 天，到期自动重登 | 手机号有日额度（RK001 流控），可降级到备用邮箱 |

两条路写进的是同一份一次性推送缓存（`ingest_push`），网页解析器按"命中即用"消费，所以**不需要开关**：App 哪一轮拿不到日电量就一个字节都不灌，sidecar/网页那条随时接管。

## 功能特性

- 账户余额、日用电（总/峰/谷/平/尖）、当月累计、年度累计电量与电费、最近 30 天与最近 12 个月图表数据
- App 通道：本地生成设备令牌、SM4/SM2/SM3 信封，直连国网网关，不经过任何第三方加密代理服务
- 按月/按年补数：同一接口可以挂多份载荷，回补历史月份的分时拆分
- RK001 流控处理：冷却到当日 23:59:59，不做无效重试；配置备用邮箱后自动降级

## 安装

### HACS

1. HACS → 集成 → **探索并添加自定义仓库**
2. 仓库地址 `https://github.com/tiejiang29/state_grid`，类别选 **集成**
3. 下载 → 重启 Home Assistant

### 手动

从 [Releases](https://github.com/tiejiang29/state_grid/releases) 下载 zip，把其中的 `custom_components/state_grid/` 整目录复制到 HA 配置对应位置后重启。

## 配置

**设置 → 设备与服务 → 添加集成 → 国家电网**

- **手机号**、**密码**：必填
- **备用邮箱**：选填，只在走网页兜底时用于流控降级
- **LLM API Key / Base URL / 模型 ID**：选填。**只有 App 通道没登录成功、要走网页登录时才会要求填**（默认地址为火山引擎豆包，也支持任何 OpenAI 兼容接口）

添加时集成会先试 App 通道登录，成功就直接建条目——也就是说，装完就能用，不需要先申请大模型。

### 修改密码

**设置 → 设备与服务 → 国家电网 → 配置**，在「新密码」里填入国网新密码并提交：集成会立即验证一次，成功才写入（失败保持旧密码并回弹错误；RK001 冷却期内会提示改后再试，避免把限流误判成密码错误）。

> 密码以 MD5 摘要形式存在 HA 的 `state_grid.config` 里，不进配置项、不进日志。App 通道用的就是同一份摘要。

## 已知限制（都是实测，不是"预计没问题"）

- **「上个月抄表」传感器恒为 0。** 95598 站点升级后，网页那条抄表接口（`c04/f03`）返回的载荷里已经没有解析器等的 `readList/billRead` 那组键——App 侧的对应端点也没找到（月度接口只给档位与结算区间，不给示数）。这只影响这一个传感器，其余数值不受影响。
- **年度分时之和会比年度累计电量少约 0.3%。** 日电量的发布口径与月结算电量本身不完全重合（实测差额 4.2 kWh / 1647.3 kWh），不是窗口算错。
- **App 会话是单份的**：在别处（例如调试脚本）重新登录会把生产会话顶掉，服务端回 `-201`。生产侧下一轮会自动重新登录。
- **令牌 15 天到期后的重登是否需要"新设备短信验证"尚未验证**，这是无人值守运行目前唯一没被证实的环节。
- RK001 是按登录标识计的日额度，换客户端姿势无效；手机号当天被限流时，网页兜底要靠备用邮箱。

## 传感器列表

| 传感器 | 说明 | 单位 |
|--------|------|------|
| 账户余额 | 电费账户余额（预付费账户为负数表示预存） | 元 |
| 年度累计用电 / 峰 / 谷 / 平 / 尖 | 年度总量与分时 | kWh |
| 年度累计电费 | 年度总电费 | 元 |
| 上个月用电 / 上个月电费 | 上月账单口径 | kWh / 元 |
| 上个月抄表 | 见上面「已知限制」，当前恒为 0 | - |
| 当月累计用电 / 峰 / 谷 / 平 / 尖 | 当月按日累计 | kWh |
| 日总用电 / 峰 / 谷 / 平 / 尖 | 最近一个出数日 | kWh |
| 最近30天每日用电、最近12个月每月用电 | 图表属性数据 | - |
| 最新日用电日期、最近刷新时间 | 数据新鲜度 | - |

## sidecar 兜底部署

网页通道需要真实浏览器时，用 `sidecar/` 下的容器：登录、解验证码、抓响应后 POST 给集成的 webhook。部署步骤、可配项和与 HA 共享标识/LLM 配置的办法写在 **[`sidecar/README.md`](sidecar/README.md)**。
